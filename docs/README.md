# Documentation

`hyperbdrctl` CLI style specifications are maintained in Chinese and English, while the CLI also supports Japanese output.

| Topic | English | 中文 |
| --- | --- | --- |
| CLI help | [CLI Help Style](cli-help-style.en.md) | [CLI Help 样式规范](cli-help-style.zh.md) |
| CLI output | [CLI Output Style](cli-output-style.en.md) | [CLI 输出样式规范](cli-output-style.zh.md) |

The documented language versions must keep the same section order, examples, parameter order,
and behavioral rules. Update the translations when changing the CLI contract.
